Clears the warnings from the community review:

- no `!important` in the stylesheet — the editor's padding override is scoped by
  view type and wins on specificity instead
- no `clip-path` or masks, which are only partially supported on older Obsidian
- the masters picker reads one folder rather than enumerating every file in the
  vault

Two fixes that came out of redrawing the triangle as an SVG shape:

- a label on a triangle is readable — triangles are outlined like the rectangle
  and the circle, and `(fill)` uses the light fill
- `(dashed)` draws a dashed *triangle*; it used to draw a dashed rectangle
  around one

No change to the file format, and nothing to migrate.
