Real pictures on a board.

Wireframes are lo-fi on purpose, but a logo is not a thing worth drawing by hand. `img:` used to be a hatched box with a cross through it, always. Now it can be the actual picture.

- **Three ways to get one in.** Drop a PNG or JPEG onto the board from your desktop, paste one from the clipboard, or drag one out of the file explorer. There is also **Wireframe: place a picture from the vault** for the keyboard, and a **Choose a picture…** button in the inspector for an image already on the board.
- **They live beside the board.** A board at `Wireframes/Login.wire` keeps its pictures in `Wireframes/Login.images/`, and the element stores `Login.images/stripe.png` — a path relative to the board, so the two can be moved together and the `.wire` file still diffs cleanly. Nothing is embedded as base64. A picture already in your vault is referenced where it lies rather than copied into a second place.
- **The file keeps its name.** A logo you can recognise in the file explorer is worth more than one named after the second it arrived. A clipboard paste has no name, so it gets a timestamp.
- **Resize them like anything else.** The handles are free, exactly as they are for a card or a table, and the picture is contained inside the box rather than stretched by them, so a logo is never squashed. `(stretch)` fills the box exactly and `(cover)` fills it by cropping, when that is what you want.
- **Exports include them.** A board is exported by serialising it into an SVG and loading that as data, and nothing inside that can fetch a file — so every picture is turned into data first. Without that step the exported PNG has holes where the logos were.

**PNG and JPEG, from your vault only.** Nothing is ever downloaded. `img: https://cdn.example.com/logo.png` is refused by name rather than fetched, and the resolver hands back a URL only for a png or jpeg that is actually in the vault. The plugin still makes exactly one kind of network request in its whole life — the AI call, from one call site, only when you ask it something. To use a logo from a website: right-click it, Copy image, and paste it onto the board.

Also in this release:

- **A long button label no longer hangs out of its button.** Every button was pinned to its designed 140px however much was written on it, so `btn: Continue with Google` spilled out both sides. Buttons, button groups and links are now at least as wide as their words.
